# Справочник: модели для кадров и видео

Обновлено: **2026-09-24**. Каждая запись — с источником. Пометка **[не подтверждено]** — проверить на своём аккаунте до продакшена. Модели нет в справочнике — формата для неё нет, выдумывать нельзя.

## Два разных промпта — не путай

| | Промпт кадра | Промпт движения |
|---|---|---|
| Для чего | сгенерировать статичную картинку | оживить готовую картинку в видео |
| Герой и место | **описываются**, якорь первой строкой | зависит от модели — у Kling **не описываются**, их даёт картинка |
| Где живёт | `shot-prompts.md`, раздел кадра | тот же раздел, отдельный блок «движение» |

В `shot-prompts.md` у каждого кадра оба блока, подписанные: `Кадр:` и `Движение (<модель>):`.

## ⛔ Выбыли — не использовать

- **Sora (OpenAI)** — приложение закрыто 26.04.2026, API отключён 24.09.2026. Замены OpenAI не объявила. Источник: help.openai.com, «What to know about the Sora discontinuation».

## Видео: оживление кадров

### Seedance 2.5 (ByteDance)

- **Версия:** 2.5, релиз 31.07.2026. Источник: seed.bytedance.com.
- **Структура:** шесть блоков — субъект → действие → место → стиль → камера → **звук**. Любой можно опустить.
- **Кадр как старт:** да, через референс-изображения. Практики советуют брать меньше референсов, чем разрешено.
- **Запреты:** отдельного поля **[не подтверждено]** — пиши в тексте формой `avoid X`.
- **Звук:** генерирует вместе с видео; прямая речь в кавычках.
- **Длительность:** до 30 с одним клипом. **9:16 — [не подтверждено]**, проверь до продакшена.

```
She turns toward camera, silk dress swaying; quiet bedroom, soft side light; warm filmic grade; slow push-in; sound: soft fabric rustle. Avoid jitter, avoid bent limbs.
```

### Kling 3.0 (Kuaishou)

- **Версия:** 3.0 (05.02.2026), Turbo и Omni — 17.06.2026. Источник: ir.kuaishou.com; гайд — klingai.com, blog.fal.ai.
- **Структура при оживлении кадра (официально):** **убери героя и место** — их даёт картинка. Веди с движения героя и языка камеры.
- **Запреты:** **отдельное поле negative prompt**, 3–7 конкретных пунктов, не общий список.
- **Звук:** нативный, липсинк на нескольких языках.
- **Длительность:** 3–15 с, 720p/1080p, **9:16 подтверждён**.

```
Движение:  she turns slowly toward the window, hair lifting in the breeze; slow push-in; soft window light
Negative:  distorted hands, warped face, jerky camera, flicker
```

### Veo 3.1 (Google)

- **Версия:** 3.1 (обычная и Fast). Источник: developers.googleblog.com, ai.google.dev/gemini-api/docs/veo.
- **Структура:** развёрнутая сцена — камера, герой, действие, место, свет, стиль. Реплика в кавычках: `she says, "..."`. Звуки — меткой `SFX:`.
- **Особенность:** **первый + последний кадр** — модель строит переход между двумя картинками.
- **Запреты:** отдельного поля **[не подтверждено]** — в тексте.
- **Длительность:** **до 8 с на клип**; длиннее — через Extend. 9:16 поддерживается.

```
Medium shot, slow tracking. A woman in an ivory silk slip dress walks toward camera, fabric catching the breeze; golden light through a tall window. SFX: fabric rustle.
```

### Google Flow — студия поверх Veo

Не отдельная модель, а интерфейс Veo 3.1. Промпт — свободным языком, как для Veo, без спецсинтаксиса. Источник: support.google.com/labs (Flow Help), blog.google.

- **Ingredients to Video** — до 3 референсов (герой, товар, стиль) + описание сцены. **Нативно 9:16.** Основной режим для нашей схемы.
- **Frames to Video** — стартовый и конечный кадр, Flow строит переход.
- **Extend** — продлить клип со звуком.
- **Scenebuilder** — собрать клипы в один ролик на таймлайне.

Для человека, который оживляет руками, Flow — самый короткий путь «кадры → ролик → монтаж» в одном месте. Отдавай ему: 3 ингредиента (карточка героя, фото товара, кадр стиля) + промпт движения на кадр.

### Grok Imagine 1.5 (xAI)

- **Версия:** 1.5 Preview, API с 03.06.2026. Источник: x.ai/news.
- **Официального гайда нет.** Практики пишут естественным языком: субъект → действие → место → камера → свет.
- **Запреты:** отдельного поля **[не подтверждено]**.
- **Длительность:** около 6 с, **до 720p**. 9:16 **[не подтверждено]**.
- **Когда брать:** быстрый дешёвый черновик, чтобы проверить идею. **Не для финального рекламного ролика** — детализации ткани и лица не хватает.

## Кадры: статичные картинки

### GPT Image 2 (OpenAI, в ChatGPT и API)

- **Версия:** gpt-image-2. Источник: OpenAI Cookbook, image-gen-models-prompting-guide (официальный).
- **Структура:** сцена → субъект → ключевые детали → ограничения. Для сложного — подписанные короткие строки, а не один абзац.
- **Консистентность:** повторять неизменные признаки в каждом промпте + фраза `Same character, new scene. Character appearance must remain unchanged. Do not redesign the character.`
- **Запреты:** здесь форма `no X` правильная — явные ограничения в тексте: `no text, no logos, no watermark`.

```
Scene: quiet bedroom, soft window light.
Subject: same woman as reference — <якорь дословно>.
Action: stands by the window, calm gaze aside.
Constraints: keep face and outfit identical to reference, no text, no logos, no watermark.
```

### Кто лучше держит одно лицо в серии кадров (сентябрь 2026)

- **Nano Banana Pro / Nano Banana 2** (Google, Gemini Flash Image) — лидер по удержанию лица, наряда и пропорций между кадрами.
- **Midjourney** — выигрывает во «вкусе», слабее в контролируемой консистентности.
- **Flux** — компромисс по гибкости, но принимает только текст, образца не видит.

**Твой `image_generate` работает на Nano Banana** (с 24.09.2026). С параметром `reference` — режим edit по карточке героя: проверено живым вызовом, держит платье, волосы, тип лица и даже мелкие детали образца. Без `reference` — обычная генерация по тексту. Цена $0.039 за кадр.

Источники: rangy.ai, screenweaver.ai (сравнения Nano Banana Pro / Midjourney / Flux).

## Сводка — что предлагать человеку

| Задача | Модель |
|---|---|
| Финальный ролик 9:16, жёсткий контроль рук и лиц | **Kling 3.0** — 9:16 подтверждён, есть поле запретов |
| Весь путь «кадры → ролик → монтаж» в одном окне | **Google Flow** |
| Реплика героини в кадре, переход между двумя кадрами | **Veo 3.1** |
| Один длинный клип до 30 с со звуком | **Seedance 2.5** — сначала проверить 9:16 |
| Быстрый черновик для проверки идеи | **Grok Imagine** |
| Статичные кадры с одним героем | **Nano Banana Pro** или **GPT Image 2** |
