# Голос — один на всю машину

Сервис `piper_server.py` держит модель Piper в памяти и озвучивает текст
для **любой** программы на этом компьютере: Nexus OS, Holovant, скрипт в
терминале, проект, которого ещё нет.

Поднимается сам вместе с остальным через `start_all.ps1`. Вручную:

```powershell
.venv\Scripts\python.exe voice_engine\piper_server.py
```

Адрес — `http://127.0.0.1:8424` (8420 занят бэкендом, 8421 — OmniVoice,
8422 — слово-будильник).

## Зачем он появился

К 25.08.2026 локальный Piper был написан **дважды и по-разному**: в Nexus OS
(`backend/services/tts.py`, модель в памяти бэкенда) и в Holovant
(`apps/web/voice-worker/piper_worker.py`, отдельный процесс с протоколом по
stdin). Оба работают. Но каждая следующая программа означала бы третью
копию — вместе с третьим разом, когда кто-то заново напорется на кириллицу
в путях espeak-ng.

Теперь голос — сервис. Новый проект получает его копированием одного файла
клиента, а модель на 60 МБ лежит в памяти в единственном экземпляре.

## Как позвать

Из терминала, в конце долгой команды:

```powershell
npm run build; .\scripts\say.ps1 "Сборка закончилась"
```

Из Python — скопировать `client.py` к себе:

```python
from client import speak, say

speak("Сборка прошла")      # вслух на этой машине
wav = say("Привет")         # WAV байтами — отдать браузеру
```

Из Node/TypeScript — скопировать `client.ts`:

```ts
import { speak, say } from "./voiceClient";
await speak("Сборка прошла");
```

Голым HTTP, откуда угодно:

```bash
curl -X POST http://127.0.0.1:8424/speak -H "Content-Type: application/json" \
     -d '{"text":"Готово"}'
```

## Ручки

| | |
|---|---|
| `GET /health` | жив ли, какие голоса загружены, сколько грузились |
| `GET /voices` | какие голоса реально скачаны |
| `POST /say` | `{text, voice?}` → WAV байтами; звук проигрывает вызывающий |
| `POST /speak` | `{text, voice?}` → проиграть здесь же, на колонках машины |
| `POST /stop` | замолчать немедленно |

`/say` — для браузера и мобильного клиента: звук должен звучать у
пользователя. `/speak` — для скриптов и терминала: там некому проигрывать
WAV, а сказать вслух надо.

## Замеры на этой машине

| | |
|---|---|
| загрузка модели при старте | 9–11 сек (платится один раз) |
| первая фраза после прогрева | ~1.9 сек (поднимается espeak) |
| дальше | ~0.8 сек на фразу |
| переключение на другой голос | ~10 сек первый раз, дальше бесплатно |

Все запрошенные голоса остаются в памяти: выгружать и грузить заново
стоило бы десять секунд на каждое переключение.

## Что НЕ переносилось и почему

**Holovant остался на своём воркере.** Это отдельный продукт, который может
уехать на чужую машину, и зависимость от сервиса Nexus OS сделала бы его
неразворачиваемым в одиночку. Дублирование здесь — плата за
самостоятельность продукта, и она осознанная.

## Ловушка Windows, решённая здесь один раз

Нативный espeak-ng внутри Piper не открывает пути с кириллицей, а имя
пользователя на этой машине — «Вадим». Лечится коротким DOS-именем (8.3),
см. `_short_path`. Та же ловушка ловила Vosk (`wakeword/server.py`) и Piper
в обоих проектах по отдельности — ради этого сервис и появился.

Вторая, найденная первым же живым вызовом: `winsound` **не умеет**
`SND_ASYNC` вместе с `SND_MEMORY` — падает с «Cannot play asynchronously
from memory». Проигрывание вынесено в поток.
